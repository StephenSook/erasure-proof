# Node-kill durability capture (local 3-node cluster, real Raft)
#
# Captured: 2026-07-10. Image: cockroachdb/cockroach:latest-v25.2. Rig: deploy/local/docker-compose.yml
# (3 nodes + HAProxy; replication factor 3, so killing one node preserves quorum).
#
# What this proves: a committed destroy-and-retain erasure survives losing a node. Each run
# seeds a subject, erases it in ONE SERIALIZABLE transaction (crdbpgx 40001 retry), kills
# roach2, then verifies from the SURVIVING replicas: wrapped key gone, decision-log row
# present, erasure record present, live embedding NULL. The killed node restarts and
# catches up. The managed cloud cluster's nodes cannot be killed by us, so this beat is
# local by necessity and disclosed as such: same SQL, same DDL, same retry semantics.
#
# Reproduce: PYTHON=$PWD/.venv-spikes/bin/python CRDB_IMAGE=cockroachdb/cockroach:latest-v25.2 bash spikes/spike3_nodekill/run.sh
